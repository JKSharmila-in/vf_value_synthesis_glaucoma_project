VF Value Synthesis

Medical AI Research Prototype for Visual Field Prediction

⚠️
Research Prototype Notice: This is a research prototype for evaluating AI-assisted Visual Field (VF) prediction from fundus images in glaucoma assessment. Not for clinical diagnosis. Use by qualified ophthalmologists / medical professionals only under appropriate institutional oversight.

About This Prototype

This tool synthesizes Visual Field values from fundus fundus (retinal) images using a Conditional Diffusion Probabilistic Model (CDPM). The model integrates optional clinical parameters (age, intraocular pressure, gender, corneal thickness) to enhance prediction accuracy.

Research Quality

Designed for clinical research and ophthalmologist evaluation

How It Works

  1. Upload Fundus Image: Provide a high-quality fundus photograph of the optic disc and macula region.
  2. Optional Clinical Data: Enter age, gender, intraocular pressure (IOP), and/or central corneal thickness (CCT). Missing fields use learned default representations.
  3. Run Prediction: The model synthesizes a 61-point Visual Field using conditional diffusion sampling.
  4. Review Results: Examine the predicted VF grid and summary statistics in context with the input fundus image.

Requirements & Inputs

Required

  • Fundus Image: JPG, PNG (minimum 256×256 pixels, recommended 512×512 or larger)

Optional

  • Age: 1–120 years
  • Gender: Male / Female
  • IOP: 0–60 mmHg
  • CCT: 200–900 µm

Important Notes

  • This prototype is not a diagnostic tool. Predictions are research outputs for professional review.
  • Missing optional clinical fields are handled by learned null tokens optimized during model training.
  • All prediction records are logged locally (non-identifiable data only).
  • The synthesized VF should be validated by qualified ophthalmologists in clinical context.
  • Model predictions are computed locally on your machine; no data is transmitted externally.
